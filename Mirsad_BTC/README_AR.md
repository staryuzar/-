# مرصاد البيتكوين — Mirsad BTC

برنامج مستقل لتحليل BTC بأربعة محركات فقط. هذا الإصدار يبني المحركات ووصلاتها ولوحة الحالة. لا يحتوي على ذكاء اصطناعي، ولا يستعمل أسعاراً مصطنعة أو صفقات محاكاة، ولا يرسل أوامر تداول في هذه المرحلة.

## المحركات الأربعة

1. **محرك السوق والمعلومات:** يتصل بواجهات البيانات العامة لـ Binance Spot وBybit Spot وOKX Spot، ويجمع السعر والشموع ودفتر الأوامر والصفقات العامة. يحفظ اللقطات والشموع والدفاتر والصفقات في SQLite.
2. **محرك التحليل البصري للرسوم:** يعالج صورة الرسم باستخدام OpenCV وقواعد هندسية تقليدية لاستخراج الأجسام الملونة والظلال والمرشحات الأولية للشموع. لا يستعمل AI. معايرة محور السعر وقراءة القيم الرقمية على الصورة لم تكتمل بعد؛ لا تعرض المرشحات كإشارات مؤكدة.
3. **محرك القرار وإدارة المخاطر:** يحسب EMA20 وEMA50 وRSI14 وATR14 من الشموع المكتملة الحقيقية، ويصدر شراء/بيع/انتظار بقواعد ثابتة. حساب الوقف والهدف وحجم المركز ومبلغ المخاطرة مسؤولية البرنامج. لا يحسب الحجم قبل وصول حقوق الحساب ومواصفات الرمز الفعلية من MT5.
4. **محرك ربط MT5:** موائم من جهة البرنامج يقرأ نبض الخبير ومواصفات الرمز والمراكز والإقرارات من مجلد Common Files. لا يصنف نوع الحساب ولا يحسب المخاطر. كتابة الأمر موجودة في البروتوكول لكنها معطلة افتراضياً ولن تستخدم قبل اكتمال الخبير التنفيذي لاحقاً.

## مصادر البيانات الحقيقية

- Binance Spot REST: https://developers.binance.com/en/docs/products/spot/rest-api
- Bybit V5 Tickers: https://bybit-exchange.github.io/docs/v5/market/tickers
- Bybit V5 Kline: https://bybit-exchange.github.io/docs/v5/market/kline
- Bybit V5 Orderbook: https://bybit-exchange.github.io/docs/v5/market/orderbook
- Bybit V5 Public Trades: https://bybit-exchange.github.io/docs/v5/market/recent-trade
- OKX V5: https://www.okx.com/docs-v5/en/

لا تستخدم مفاتيح API أو خدمات مدفوعة في محرك السوق. قد تمنع بعض المناطق الوصول إلى منصة؛ عندها تظهر OFFLINE أو PARTIAL ويستمر البرنامج مع المصادر الأخرى المتاحة.

## التشغيل على Windows

داخل مجلد Mirsad_BTC:

    py -3.11 -m venv .venv
    .venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -r requirements.txt

نافذة PowerShell الأولى:

    python run_mirsad.py

نافذة ثانية:

    streamlit run dashboard.py

لإجراء اتصال حقيقي مرة واحدة:

    python scripts/live_smoke.py

ستظهر اللوحة حالة كل محرك بناءً على ردود الاتصال الفعلية والنبضات. لا تُولّد بيانات بديلة عند فشل المصادر.

## التحقق والحدود

يفحص GitHub Actions بناء وحدات Python ثم يتصل بمصادر السوق العامة فعلياً. إذا لم يستجب أي مصدر، يفشل فحص الاتصال ولا يصطنع بيانات. لا يضع الفحص أي أمر تداول.

لا يوجد خبير تنفيذي نهائي حتى الآن؛ ملف EA القديم ذو القراءة فقط ليس الخبير النهائي. لا يرسل runtime أي صفقة. سنجهز الخبير بعد إكمال ربط المحركات والتحقق منها. اللوحة لا تعني ضمان الربح أو صحة كل إشارة.
