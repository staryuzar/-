# مرصاد البيتكوين — Mirsad BTC

منصة مستقلة لتحليل البيتكوين بأربعة محركات فقط، مع بيانات سوق فعلية، قواعد تحليل كلاسيكية، ولوحة مراقبة عربية. لا يوجد ذكاء اصطناعي، ولا أسعار مصطنعة، ولا صفقات محاكاة، ولا اشتراك أو API مدفوع في المحرك الأساسي.

## ترتيب المحركات المعتمد

1. **المحرك الأول — السوق والمعلومات:** يجمع السعر والشموع بستة أطر زمنية (1m, 5m, 15m, 1h, 4h, 1d)، ودفتر الأوامر، والصفقات العامة وتدفق Taker من Binance Spot وBybit Spot وOKX Spot. يحفظ البيانات في SQLite. كل منصة تبقى معلّمة بمصدرها.
2. **المحرك الثاني — تحليل الرسوم والصور:** يحلل لقطة رسم حقيقية باستخدام OpenCV وقواعد هندسية لتحديد الشموع والظلال والأنماط المرشحة. لمعايرة تحويل بكسلات الرسم إلى أسعار، توفر اللوحة حقولاً لرمز الأداة وإطارها وأعلى/أدنى سعر ظاهرين وحدود منطقة الرسم. لا تدخل الصورة في تصويت القرار قبل نجاح المعايرة وتطابق الرمز.
3. **المحرك الثالث — جسر MT5 والخبير:** قناة نقل ثنائية الاتجاه عبر مجلد Common Files باسم MirsadBTC. يستقبل نبض الخبير والحساب ومواصفات الرمز والمراكز وإقرارات التنفيذ، وينقل أوامر مركز القرار إليه. لا يصنف نوع الحساب ولا يحسب المخاطر ولا يتخذ قراراً. ملف الخبير التنفيذي ما زال المرحلة التالية.
4. **المحرك الرابع — مركز القرار وإدارة المخاطر:** يستقبل المحركات 1 و2 و3. يستخدم قواعد EMA/RSI/ATR متعددة الأطر وتدفق الصفقات مع شرط توافق الشارت المعاير. يصدر BUY/SELL/WAIT. يحسب الوقف والهدف وحجم المركز ومبلغ المخاطرة داخل البرنامج اعتماداً على حقوق الحساب ومواصفات الرمز الفعلية التي أرسلها الجسر.

## التكامل الحالي

- Engine 1 → Engine 4: موصول.
- Engine 2 → Engine 4: موصول؛ ويشترط تطابق الرمز والإطار والمعايرة السعرية.
- Engine 3 → Engine 4: موصول من جهة البرنامج وينتظر الخبير ليبدأ نبض MT5 الفعلي.
- Engine 4 → Engine 3: منشئ أمر MIR1 موجود، لكن نشر الأوامر معطل افتراضياً حتى يكتمل الخبير ويجتاز اختبارات الاستلام والإقرار.
- لوحة Streamlit تعرض حالة المحركات الأربعة وتغذية السوق وتوافق الأطر والقرار والمخاطر واتصال الجسر، وتتحدث دورياً.

## مصادر السوق

- Binance Spot: https://developers.binance.com/en/docs/products/spot/rest-api
- Bybit V5: https://bybit-exchange.github.io/docs/v5/market/tickers
- OKX V5: https://www.okx.com/docs-v5/en/

المصادر العامة قد تحجب بعض المناطق أو عناوين IP. يظهر ذلك OFFLINE، ولا تُنشأ بيانات بديلة.

## التشغيل على Windows

داخل مجلد Mirsad_BTC:

    py -3.11 -m venv .venv
    .venv\Scripts\Activate.ps1
    python -m pip install --upgrade pip
    pip install -r requirements.txt

نافذة أولى: python run_mirsad.py
نافذة ثانية: streamlit run dashboard.py

ارفع صورة الشارت من اللوحة وأدخل أعلى وأدنى سعر ظاهرين على المحور. شغّل runtime قبل فتح اللوحة.

## المرحلة التالية

بعد تثبيت وصلات المحركات الثلاثة إلى مركز القرار، نجهز خبير MQL5 تنفيذياً يستلم أوامر البرنامج ويرسل نبضه ومواصفات الرمز والمراكز والإقرارات. مسؤولية المخاطر تبقى بالكامل في المحرك الرابع. لا ترسل اختبارات البناء أي أوامر تداول.
