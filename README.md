# المساعد الذكي — Aurora Control Room

واجهة عربية للمساعد المحلي تجمع المحادثة والذاكرة المحلية وأدوات Windows والتحكم في Chrome والتكامل مع MetaTrader 5.

> **للاستئناف في أي محادثة لاحقة:** اقرأ أولًا [دفتر حالة المشروع العربي](.github/PROJECT_STATE_AR.md). يحتوي على آخر نقطة مؤكدة، ونتائج الاختبار، وروابط التشغيل، والمهام المتبقية. حدّثه ولا تبدأ العمل من الصفر.

## حالة الاختبار الحالية — 2026-10-19

- **Windows / Python 3.11:** نجحت 347 من 347 اختبارًا؛ 0 فشل، 0 أخطاء، 0 متخطاة.
- **Windows / Python 3.13:** نجحت 347 من 347 اختبارًا؛ 0 فشل، 0 أخطاء، 0 متخطاة.
- **Streamlit:** فحص الصحة والصفحة الرئيسية أعادا HTTP 200 في CI.
- **Chrome الفعلي:** نجحت 7/7 فحوصات المتصفح الآلية.
- **MetaTrader 5:** عُثر على الملف التنفيذي وشُغّلت المنصة؛ جُمّع مستشار تجريبي مؤقت في MetaEditor مع 0 أخطاء و0 تحذيرات؛ أكد التقرير أن سجل المنصة سجّل التفويض إلى خادم Headway التجريبي. لم تُفتح أي صفقة ولم يُشغّل Strategy Tester. أعاد المُثبّت رمز خروج 1 رغم وجود المنصة وتشغيلها؛ انظر التقرير التفصيلي.
- **الاختبار الشامل عبر واجهة المساعد وGemini:** يجب فحص نتيجته النهائية في [GitHub Actions](https://github.com/staryuzar/-/actions)؛ لا يُعدّ النجاح مثبتًا قبل ظهور تقرير PASS الذي يثبت استدعاء أداة المتصفح وقراءة محتوى الموقع بالفعل.

## الحزمة المصححة

من تبويب **Actions** افتح آخر تشغيل ناجح لـ **Aurora Windows validation** ونزّل Artifact باسم `Aurora-Control-Room-v2.4.0-patched`. الحزمة الأصلية تبقى محفوظة كما هي؛ تُطبّق الإصلاحات على نسخة منفصلة قابلة لإعادة البناء.

## ملاحظات الثقة والاستمرارية

- تُحفظ وصفة تجهيز المختبر وسكربتات الاختبار في المستودع كي يمكن إعادة بناء بيئة Windows/Python/MT5 مستقبلًا.
- لا تُحفظ كلمات مرور أو مفاتيح API أو ملفات `.env` في Git. تُقرأ أسرار الاختبارات من GitHub Actions secrets فقط.
- عوامل GitHub-hosted Actions مؤقتة وتُزال بعد انتهاء التشغيل؛ لا يمكن إبقاء نفس آلة Windows المثبت عليها MT5 حية عبر تشغيلات Actions العادية. تبقى السكربتات والتقارير الملتزمة في GitHub، أما Artifacts فلها مدة احتفاظ محددة من GitHub.
- نجاح اختبارات الوحدة أو فتح نافذة MT5 لا يثبت عمل جميع الوظائف على جهاز Windows 10 الخاص بالمستخدم ولا يثبت نجاح استراتيجية تداول. يلزم اختبار الأثر الفعلي وتسجيل حدوده بشكل مستقل.
