# Bitcoin Intelligence Lab — مختبر ذكاء البيتكوين

برنامج مستقل لتحليل BTC، يجمع بيانات السوق الحقيقية ويُشغّل محركات متخصصة ثم يوحّد أدلتها في مركز قرار قابل للتفسير داخل لوحة Streamlit. البرنامج في مرحلة استكمال المحركات وتدقيق اللوحة؛ **ربط خبير MT5 مؤجل عمداً** حتى يكتمل هذا العمل. وسيط التنفيذ المخطط لاحقاً هو Headway حصراً، وليس أي منصة من منصات البيانات.

الملفات في هذا المجلد والفرع `bitcoin-intelligence-lab` مستقلة عن برنامج الذهب.

## مصادر البيانات ليست وسطاء تنفيذ

- Binance Spot وBinance USDⓈ-M وBybit Linear وOKX Spot/Swap وDeribit هي مصادر قراءة بيانات السوق فقط.
- لا يرسل البرنامج أوامر إلى Binance أو Bybit أو OKX أو Deribit.
- عندما تكتمل المحركات واللوحة ويجتاز البرنامج مرحلة التدقيق، يكون **Headway عبر MT5** وسيط التنفيذ الوحيد في مرحلة الربط المستقبلية.
- لا توجد حالياً قراءة لحساب Headway أو ملفاته، ولا إرسال أوامر أو إغلاق مراكز. ملفات الخبير والجسر موجودة محفوظة في المستودع كمرحلة لاحقة، لكنها غير موصولة بتطبيق Streamlit.

## محركات البرنامج الحالية

1. **Spot:** شموع Binance المكتملة، دفتر Spot وصفقات السوق المجمعة، مع تحقق حداثة البيانات.
2. **Futures:** Funding وOpen Interest وTaker Buy/Sell من Binance USDⓈ-M، مع Bybit V5 كمصدر مشتقات احتياطي عند التقادم أو الفشل.
3. **الاتجاه متعدد الأطر:** 1D و4H و1H و15M و5M و1M؛ تحليل Top-down بأوزان حسب الدور، مع رفض الشموع القديمة والناقصة.
4. **السيولة وتدفق الأوامر:** Spread وDepth وOrder Book Imbalance وAggressor Buy/Sell Delta.
5. **بنية السوق:** Volume Profile للعينة المتاحة، POC/VAH/VAL/Delta، وVWAP، وRelative Volume، وRealized Volatility، وRange Expansion.
6. **إشارة بنية السوق في مركز القرار:** موقع السعر إلى Session VWAP ودلتا عينة الصفقات، بشرط اكتمال التغطية وحداثة البيانات.
7. **دفاتر أوامر متعددة المنصات:** Binance Spot وBybit Linear وOKX Spot عبر WebSocket، مع Snapshot/Delta وقواعد تسلسل مختلفة لكل منصة، ثم مقارنة Imbalance دون جمع أحجام عقود غير متجانسة.
8. **محرك التصفية:** Binance USDⓈ-M وBybit Linear وOKX SWAP، مع حفظ الأحداث وملخص Long/Short. التصفية طبقة مخاطر وتحذير، وليست تصويتاً اتجاهياً منفرداً.
9. **محرك خيارات Deribit:** ATM IV حسب الانتهاء، و25-delta Risk Reversal، وPut/Call OI، وGreeks وGamma-weighted OI وصفي. يبقى سياق تقلب ومراكز بطيئاً، لا إشارة دخول مباشرة.
10. **سياق أبطأ:** mempool.space وCFTC TFF وCoin Metrics Community وDeribit DVOL.
11. **مركز القرار:** يدمج الاتجاه وتدفق الأوامر والمشتقات وبنية السوق وتوافق دفاتر المنصات، يعيد تطبيع الأوزان عند غياب محرك اختياري، ويُصدر BUY/SELL/HOLD مع الأسباب والتحذيرات والحواجز.
12. **مراقب صحة المصادر والاتصالات:** freshness وcoverage وheartbeat وحالة الدفاتر، مع التمييز بين اتصال قناة التصفيات الهادئة وبين heartbeat متوقف؛ لا يضيف صوتاً اتجاهياً.

### منطق أوزان القرار الحالي

الأوزان الأساسية: الاتجاه الفني 35%، تدفق الأوامر 25%، المشتقات 20%، بنية السوق 10%، وتوافق دفاتر المنصات 10%. تُعاد موازنة الأوزان بين المجالات المتاحة بعد التحقق من حداثتها. ومع ذلك لا تستطيع محركات بنية السوق أو توافق المنصات أن تحل محل الحد الأدنى من الأدلة الأساسية: محرك الاتجاه مع تدفق الأوامر أو المشتقات. التصفية والخيارات والسياق المؤسسي تحذيرات ومعلومات مساندة، لا أصواتاً اتجاهية تلقائية.

هذه الدرجة **درجة أدلة اتجاهية وليست احتمال ربح**.

## تثبيت وتشغيل Windows

افتح PowerShell وانتقل إلى مجلد `Bitcoin_Intelligence_Lab` داخل المستودع:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[ui,market-data]"
```

**1. شغّل جامع بيانات السوق في نافذة PowerShell أولى:**

```powershell
python -m bitcoinlab.market_stream --symbol BTCUSDT --venues binance,bybit,okx --depth 50 --db data/market_stream.sqlite
```

الجامع يقرأ دفاتر الأوامر ويبث أحداث التصفية العامة، ويعيد الاتصال عند الانقطاع ويحفظ عينات العمق والأحداث في SQLite. يمكن تعطيل بث التصفية اختيارياً بإضافة `--no-liquidations`.

**2. شغّل لوحة البرنامج في نافذة PowerShell ثانية:**

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

تقرأ اللقطة واللوحة قاعدة SQLite بوضع read-only، وتعرض حالة الاتصالات وآخر Bid/Ask وSpread وImbalance وأحداث التصفية. مراقب صحة المصادر يراجع عمر دفتر الأوامر وheartbeat؛ كما يميز القنوات الحدثية المتصلة التي لا تملك تصفية جديدة عن القناة التي توقف heartbeat الخاص بها. عند توقف الجامع أو تقادم البيانات تظهر الحالة stale/recovering بدلاً من التعامل مع اللقطة القديمة كبيانات حية.

### حالة ربط MT5

لا تشغّل خبير Bitcoin Intelligence Lab ولا تربطه باللوحة في هذه المرحلة. تم تعطيل كل استدعاءات الجسر والتنفيذ في تطبيق Streamlit، وحذف سير عمل Headway الآلي من الفرع حتى لا يسبق ربط الخبير اكتمال المحركات. ملفات EA وBridge محفوظة للمراجعة والتطوير اللاحق فقط.

عند اكتمال البرنامج واجتياز تدقيقه، نعيد مرحلة Headway: التحقق من خادم Headway-Demo والحساب والرمز وخصائص العقد، ثم اختبار دورة الأمر والإقرار وإدارة المراكز على MT5. لا نعتبر ذلك جزءاً من النسخة الحالية.

## الاختبارات والحدود

```powershell
python -m compileall -q bitcoinlab app.py
python -m unittest discover -s tests -v
```

GitHub Actions يشغّل الاختبارات على Python 3.12 و3.13، ويفحص بدء Streamlit ومصادر BTC العامة. آخر CI ناجح رقم #302 شغّل 169 اختباراً بنجاح على الإصدارين. اختبارات WebSocket تختبر قواعد الرسائل وإعادة المزامنة محلياً؛ لا تثبت وحدها استمرار الاتصالات الحية لعدة ساعات على جهاز Windows.

حدود مهمة:
- Binance forceOrder مصدر عيّني محدود بتحديثات لا تمثل كل التصفية.
- OKX وBybit يعرضان كميات/أسعار مرجعية تختلف عن حجم BTC أو سعر التنفيذ؛ لذلك لا تُجمع الأرقام دون بيانات عقد موثقة.
- عينة Volume Profile الحالية ليست جلسة كاملة، وVWAP الحالي مشتق من الشموع، لا كل تنفيذ منفرد.
- خيارات Deribit وصفية، وOpen Interest لا يكشف دفتر صانع السوق ولا يساوي Net Dealer GEX.
- CFTC أسبوعي، وCoin Metrics Community خاضع لشروطه.
- فحوص CI لا تثبت الربحية، ولا تُعد اختباراً ميدانياً مستمراً لجميع تدفقات WebSocket.

لا توجد حتى الآن نتائج ربحية موثقة أو ادعاء بأن الاستراتيجية مربحة.
