# Bitcoin Intelligence Lab — مختبر ذكاء البيتكوين

برنامج مستقل لتحليل BTC، يجمع بيانات السوق الحقيقية ويُشغّل محركات متخصصة ثم يوحّد أدلتها في مركز قرار قابل للتفسير داخل لوحة Streamlit. أُضيفت حلقة تنفيذ مستقلة تربط القرار المركزي بخبير MT5 عبر ملفات Common\\Files؛ Headway هو وسيط التنفيذ الوحيد، بينما تبقى Binance وBybit وOKX وDeribit مصادر بيانات للقراءة فقط.

الملفات في هذا المجلد والفرع `bitcoin-intelligence-lab` مستقلة عن برنامج الذهب.

## مصادر البيانات ليست وسطاء تنفيذ

- Binance Spot وBinance USDⓈ-M وBybit Linear وOKX Spot/Swap وDeribit هي مصادر قراءة بيانات السوق فقط.
- لا يرسل البرنامج أوامر إلى Binance أو Bybit أو OKX أو Deribit.
- **Headway عبر MT5** هو وسيط التنفيذ الوحيد؛ لا توجد أوامر إلى Binance أو Bybit أو OKX أو Deribit.
- خبير MQL5 ينفّذ الأوامر التي تنشرها حلقة `bitcoinlab.execution_loop` من القرار المركزي، ولا ينشئ إشارات مستقلة داخل `OnTick`.
- اللوحة تقرأ نبض الخبير والمراكز ونبض حلقة التنفيذ للعرض فقط؛ عملية التنفيذ منفصلة عن إعادة تحميل Streamlit.
- ملف الحالة لا يخزن تصنيف الحساب؛ يتحقق الجسر من اسم خادم Headway، وحداثة النبض، والرمز، والأسعار، وصلاحية التنفيذ في الطرفية.
- الحدود الافتراضية للخبير: مخاطرة محسوبة من `OrderCalcProfit` لا تتجاوز 0.5% من حقوق الحساب للمركز الواحد، ومركز واحد للخبير في الوقت نفسه. الحجم الافتراضي للأمر 0.01 لوت، ويرفض الخبير الحجم إن لم يطابق مواصفات الوسيط.

## محركات البرنامج الحالية

1. **Spot:** شموع Binance المكتملة، دفتر Spot وصفقات السوق المجمعة، مع تحقق حداثة البيانات.
2. **Futures:** Funding وOpen Interest وTaker Buy/Sell من Binance USDⓈ-M، مع Bybit V5 كمصدر مشتقات احتياطي عند التقادم أو الفشل.
3. **الاتجاه متعدد الأطر:** 1D و4H و1H و15M و5M و1M؛ تحليل Top-down بأوزان حسب الدور، مع رفض الشموع القديمة والناقصة.
4. **السيولة وتدفق الأوامر:** Spread وDepth وOrder Book Imbalance وAggressor Buy/Sell Delta، مع سجل صفقات حيّ متعدد المنصات.
5. **بنية السوق:** Volume Profile للعينة المتاحة، POC/VAH/VAL/Delta، وVWAP، وRelative Volume، وRealized Volatility، وRange Expansion.
6. **إشارة بنية السوق في مركز القرار:** موقع السعر إلى Session VWAP ودلتا عينة الصفقات، بشرط اكتمال التغطية وحداثة البيانات.
7. **دفاتر أوامر متعددة المنصات:** Binance Spot وBybit Linear وOKX Spot عبر WebSocket، مع Snapshot/Delta وقواعد تسلسل مختلفة لكل منصة، وحفظ لقطات العمق التاريخية.
8. **محرك التصفية:** Binance USDⓈ-M وBybit Linear وOKX SWAP، مع حفظ الأحداث وملخص Long/Short وخريطة تجمعات سعرية حسب المنصة ونوع السعر المرجعي ووحدة الحجم. التصفية طبقة مخاطر وتحذير، وليست تصويتاً اتجاهياً منفرداً.
9. **محرك خيارات Deribit:** ATM IV حسب الانتهاء، و25-delta Risk Reversal، وPut/Call OI، وGreeks وGamma-weighted OI وصفي. يبقى سياق تقلب ومراكز بطيئاً، لا إشارة دخول مباشرة.
10. **سياق أبطأ:** mempool.space وCFTC TFF وCoin Metrics Community وDeribit DVOL، مع مؤشرات يومية اختيارية MVRV وRealized Cap وMVRV Z وNUPL مشتق عند توفر المقاييس.
11. **مركز القرار:** يدمج الاتجاه وتدفق الأوامر والمشتقات وبنية السوق وتوافق دفاتر المنصات، يعيد تطبيع الأوزان عند غياب محرك اختياري، ويُصدر BUY/SELL/HOLD مع الأسباب والتحذيرات والحواجز.
12. **مراقب صحة المصادر والاتصالات:** freshness وcoverage وheartbeat وحالة الدفاتر، مع التمييز بين اتصال قناة التصفيات الهادئة وبين heartbeat متوقف؛ لا يضيف صوتاً اتجاهياً.
13. **CVD متعدد المنصات وFootprint:** Binance USDⓈ-M وBybit Linear وOKX Spot، إزالة تكرار وحفظ ذري في SQLite، دلتا 1m/5m/15m/1h/4h وملفات سعرية POC/VAH/VAL لكل Venue ونوع سوق.
14. **Heatmap تاريخية للعمق:** متوسط/وسيط/حجم حالي واستمرار ظهور مستويات السعر، مع Pull/Stack proxy لا يقيس الاختفاء وحده كإلغاء مؤكد.
15. **مقارنة المشتقات بين المنصات:** Basis وMark/Index وFunding المكافئ لـ8h حسب فترة التسوية، وOI بوحدات المصدر دون جمع العقود مع BTC أو USD أو USDT.
16. **ماسح أحداث السوق:** اختراقات 20 شمعة مكتملة، قفزات الحجم، توسع المدى، اختلال الدفتر، السبريد الواسع، اختلاف CVD، وتشتت التمويل/الـBasis وضغط التصفية؛ أحداث سياقية فقط.
17. **خريطة تصفية سعرية:** تجميع الأحداث إلى نطاقات سعرية منفصلة حسب Venue/market type/side/quantity unit/reference-price kind، مع إظهار Notional USD فقط حيث يقدمه المصدر، وتوضيح التغطية الجزئية.
18. **محرك On-chain يومي:** قراءة Coin Metrics Community الاختيارية لـMVRV وMarket/Realized Cap وMVRV Z؛ واشتقاق NUPL بصيغة موضحة، مع Freshness وسجل 7 أيام. لا يعرض SOPR دون مصدر صريح، ولا يدخل التصويت اللحظي.

### منطق أوزان القرار الحالي

الأوزان الأساسية الخمسة: الاتجاه الفني 35%، تدفق الأوامر 25%، المشتقات 20%، بنية السوق 10%، وتوافق دفاتر المنصات 10%. يدخل CVD المستمر ضمن مجال Orderflow، بينما Heatmap وFunding/Basis/OI المقارنة والماسح والتصفيات والخيارات سياق وتحذيرات ولا تنشئ أصواتاً إضافية. تُعاد موازنة الأوزان بين المجالات المتاحة بعد التحقق من حداثتها. ومع ذلك لا تستطيع محركات بنية السوق أو توافق المنصات أن تحل محل الحد الأدنى من الأدلة الأساسية: محرك الاتجاه مع تدفق الأوامر أو المشتقات. التصفية والخيارات والسياق المؤسسي تحذيرات ومعلومات مساندة، لا أصواتاً اتجاهية تلقائية.

هذه الدرجة **درجة أدلة اتجاهية وليست احتمال ربح**.

## تثبيت وتشغيل Windows

افتح PowerShell وانتقل إلى مجلد `Bitcoin_Intelligence_Lab` داخل المستودع:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[ui,market-data]"
```

**1. شغّل جامع بيانات السوق في نافذة PowerShell أولى:**

```powershell
python -m bitcoinlab.market_stream --symbol BTCUSDT --venues binance,bybit,okx --depth 50 --db data/market_stream.sqlite
```

الجامع يقرأ دفاتر الأوامر ويبث أحداث الصفقات والتصفية العامة، ويعيد الاتصال عند الانقطاع ويحفظ عينات العمق والصفقات والتصفيات وFootprint في SQLite. يمكن تعطيل بث التصفية بإضافة `--no-liquidations` أو تعطيل الصفقات بإضافة `--no-trades`.

**2. شغّل لوحة البرنامج في نافذة PowerShell ثانية:**

```powershell
.\.venv\Scripts\Activate.ps1
streamlit run app.py
```

تقرأ اللقطة واللوحة قاعدة SQLite بوضع read-only، وتعرض حالة الاتصالات وآخر Bid/Ask وSpread وImbalance وأحداث التصفية. مراقب صحة المصادر يراجع عمر دفتر الأوامر وheartbeat؛ كما يميز القنوات الحدثية المتصلة التي لا تملك تصفية جديدة عن القناة التي توقف heartbeat الخاص بها. عند توقف الجامع أو تقادم البيانات تظهر الحالة stale/recovering بدلاً من التعامل مع اللقطة القديمة كبيانات حية.

### ربط Headway عبر MT5 — حلقة تنفيذ مستقلة

تشغيل الجامع واللوحة لا يشغّل التداول تلقائياً. بعد فتح منصة MT5 وتسجيل الدخول إلى خادم Headway على الجهاز الدائم، أرفق `BitcoinIntelligenceLabEA.ex5` على مخطط BTCUSD الذي يوفره الوسيط، وفعّل Algo Trading. يرفض الخبير أي رمز لا يحتوي BTC، ولا يقرأ تصنيف الحساب أو يخزنه.

**3. شغّل حلقة التنفيذ في نافذة PowerShell ثالثة** من مجلد `Bitcoin_Intelligence_Lab`:

```powershell
.\.venv\Scripts\Activate.ps1
$env:BTCIL_ENABLE_EXECUTION = "1"
python -m bitcoinlab.execution_loop --interval-seconds 30 --volume 0.01
```

- الحلقة تطلب لقطة السوق، ثم تستخدم قرار `central_decision` وحده. إذا كان القرار `HOLD` أو توجد حواجز، لا تنشر أمراً.
- إذا لم توجد مراكز للخبير ونشأ قرار BUY/SELL صالح وحديث، تنشر أمر OPEN بمهلة 60 ثانية ومستويات SL/TP محسوبة من ATR وسعر الوسيط.
- إذا كان هناك مركز للخبير وعكس مركز القرار الاتجاه بوضوح، تنشر CLOSE لتذكرة واحدة في كل دورة. `HOLD` لا يغلق المركز. معرّف أمر الإغلاق ثابت لكل تذكرة لمنع التكرار.
- الخبير يعيد فحص خادم Headway واتصال الطرفية وسماح التداول وسبريد/حجم/مسافة SL/TP وحد مخاطرة حقوق الحساب قبل إرسال `OrderSend`.
- يحدد الخبير سقف خسارة 0.5% من Equity لكل دخول، وسقف سحب يومي 2% افتراضياً من خط الأساس الذي يلتقطه عند أول تهيئة في يوم خادم الوسيط ويحتفظ به عند إعادة تشغيل MT5. عند بلوغ الحد تتوقف المداخل الجديدة، وتظل أوامر إغلاق المراكز متاحة. إذا أُرفق الخبير لأول مرة بعد خسائر سابقة في اليوم، يبدأ القياس من وقت التهيئة، وليس من افتتاح اليوم بأثر رجعي.
- تأكيد `FILLED/CLOSED` يأتي من سجل صفقات الوسيط وحدث `OnTradeTransaction`؛ كلمة `published` تعني أن الأمر كُتب في ملف Common Files فقط، وليست دليلاً على التنفيذ.
- لا تستبدل الحلقة أمراً ما زال ينتظر إقراراً أو تسوية تعبئة جزئية. إذا انتهت مهلة أمر ولم يستهلكه EA، تعيد إصداره بمعرّف محاولة جديد؛ وإذا ثبت أن EA استلمه ولم يظهر ACK نهائي، توقف التنفيذ للمراجعة بدلاً من احتمال تكرار الصفقة.
- أوقف الحلقة بـ `Ctrl+C` عند الحاجة. ستبقى مستويات SL/TP المرسلة إلى الوسيط على المراكز المفتوحة، لكن المراقبة المركزية وإشارات الإغلاق الجديدة تتوقف؛ أبقِ MT5 والخبير عاملين لتحديث حالة المركز.
- اجعل الطرفية وحلقة التنفيذ على جهاز أو VPS مستمر التشغيل. GitHub-hosted Windows runner مؤقت: يصلح للتجميع والاختبارات، لكنه يتوقف بعد انتهاء المهمة ولا يصلح لإدارة مركز مفتوح باستمرار.
- ملف الحالة وواجهة اللوحة تعرض نبض EA، ونبض حلقة التنفيذ، وآخر نتيجة دورة، والمراكز التابعة لـMagicNumber فقط.

لإجراء فحص بلا تداول، اترك `BTCIL_ENABLE_EXECUTION` غير مضبوط؛ عندها ترفض الحلقة البدء. خيار `--once` ينفذ دورة واحدة فقط.

## الاختبارات والحدود

```powershell
python -m compileall -q bitcoinlab app.py
python -m unittest discover -s tests -v
```

GitHub Actions يشغّل الاختبارات على Python 3.12 و3.13، ويفحص تجميع الحزمة وبدء Streamlit ومصادر BTC العامة وعقود EA والجسر. Workflow Windows مستقل يجمع ملف EA الحقيقي بـMetaEditor ويشغّل الجامع وSQLite وStreamlit على Windows. فحص CI لا يثبت الربحية، ولا يبقي MT5 عاملاً بعد انتهاء runner.

حدود مهمة:
- Binance forceOrder مصدر عيّني محدود بتحديثات لا تمثل كل التصفية.
- OKX وBybit يعرضان كميات/أسعار مرجعية تختلف عن حجم BTC أو سعر التنفيذ؛ لذلك لا تُجمع الأرقام دون بيانات عقد موثقة.
- عينة Volume Profile الحالية ليست جلسة كاملة، وVWAP الحالي مشتق من الشموع، لا كل تنفيذ منفرد.
- خيارات Deribit وصفية، وOpen Interest لا يكشف دفتر صانع السوق ولا يساوي Net Dealer GEX.
- CFTC أسبوعي، وCoin Metrics Community خاضع لرخصة الاستخدام المجتمعي غير التجاري؛ بعض مقاييس On-chain اختيارية وقد تكون غير متاحة في Community tier. MVRV/NUPL اليومي سياق بطيء فقط، وSOPR غير موصول.
- فحوص CI لا تثبت الربحية، ولا تُعد اختباراً ميدانياً مستمراً لجميع تدفقات WebSocket.

لا توجد حتى الآن نتائج ربحية موثقة أو ادعاء بأن الاستراتيجية مربحة.
