# Bitcoin Intelligence Lab — مختبر ذكاء البيتكوين

برنامج مستقل لتحليل BTC وإصدار قرار مركزي قابل للتفسير، مع لوحة Streamlit وخبير MT5 منفصل لتنفيذ أوامر اللوحة ومتابعة المراكز على حساب Headway-Demo. كل الملفات في هذا المجلد والفرع `bitcoin-intelligence-lab`؛ لا يعدّل هذا العمل برنامج الذهب أو الفرع الرئيسي.

## ما يعمل في الإصدار الحالي

1. **Spot:** شموع Binance المكتملة، دفتر الأوامر، وصفقات السوق المجمعة.
2. **Futures:** funding وOpen Interest وTaker Buy/Sell من Binance USDⓈ-M.
3. **محركات القرار:** EMA وRSI وATR والزخم والكسر، سيولة دفتر الأوامر، تدفق الصفقات، ومحرك المشتقات.
4. **سياق أبطأ معروض منفصلًا:** شبكة/تعدين/Mempool من mempool.space، تمركز CFTC TFF لعقود CME Bitcoin وMicro Bitcoin (133741/133742)، نشاط يومي من Coin Metrics Community، وتقلب الخيارات الضمني Deribit DVOL.
5. **لوحة مستقلة:** تحديث تلقائي للبيانات السريعة وحالة MT5، مع تخزين مؤقت لمصادر السياق الأبطأ لتجنب الاستعلام المتكرر.
6. **تنفيذ MT5:** أمر مركزي من اللوحة عبر MT5 Common Files، وإقرار من الخبير وحالة المراكز والأرباح/الخسائر.
7. **إدارة المراكز:** عند تفعيل وضع التنفيذ التلقائي، لا يكرر مركزًا في الاتجاه نفسه؛ يبقي المركز عند HOLD؛ وعند قرار معاكس مؤكد يغلق المركز المضاد أولًا، ثم يفتح الاتجاه الجديد بعد تأكيد الإغلاق.

## القرار ومصادر البيانات

- لا تتطلب بيانات المصادر العامة مفاتيح AI أو مفاتيح API.
- Spot هو شرط أساسي، والقرار يحتاج مجالين نشطين على الأقل من الفني والسيولة والمشتقات. إذا فشل أحد المجالات يُعاد توزيع الأوزان بين المجالات المتاحة وتُعرض التحذيرات.
- funding وOpen Interest لا يقرران الاتجاه بمفردهما. التمويل المتطرف يُعامل كازدحام محتمل، وOpen Interest يقيس العقود المفتوحة لا اتجاهها وحده.
- CFTC وCoin Metrics وDVOL وبيانات الشبكة سياق مستقل ولا تدخل كتصويت لحظي في قرار الدخول.
- الدرجة اتجاهية وليست احتمال ربح.

## التشغيل على Windows

1. ثبّت Python 3.12 أو أحدث.
2. أنشئ بيئة افتراضية: `py -3.12 -m venv .venv`
3. فعّلها ثم نفّذ: `python -m pip install -e ".[ui]"`
4. شغّل: `streamlit run app.py`
5. اختر الرمز والفاصل. التحديث التلقائي يعمل افتراضيًا كل 15 ثانية ويمكن تعديله من اللوحة.
6. ضع `BitcoinIntelligenceLabEA.mq5` داخل `MQL5/Experts`، ثم ترجم الملف في MetaEditor وأرفقه بمخطط BTC لدى Headway-Demo.
7. ابدأ أولًا بوضع المراقبة اليدوي. مفتاح «التنفيذ والإدارة التلقائية» يفعّل إرسال أوامر اللوحة ومتابعة المراكز؛ لا يعمل هذا الوضع إذا لم يكن الخبير جاهزًا أو لم تكن حالة البيانات حديثة وصالحة.

يقتصر الخبير افتراضيًا على حساب Headway-Demo، ويتحقق من خصائص اللوت وأسعار SL/TP وصلاحية الأمر لدى الوسيط. الخبير لا يولّد إشارات مستقلة في `OnTick`؛ القرار المركزي للوحة، والخبير منفّذ ومبلّغ عن التنفيذ. يبقى SL/TP المرسل مع الصفقة حماية لدى الوسيط، بينما لا يغلق محرك الإدارة المركز بسبب HOLD.

## الاختبارات

```powershell
python -m compileall -q bitcoinlab app.py
python -m unittest discover -s tests -v
```

GitHub Actions يشغّل اختبارات Python على 3.12 و3.13 واختبار بدء Streamlit وفحصًا منفصلًا للاتصال بمصادر BTC العامة. ترجمة MetaEditor التي نفذتها محليًا مستقلة عن اختبارات Python.

## الحدود الحالية

لا توجد نتائج ربحية موثقة أو ادعاء بصلاحية استراتيجية. مصادر Binance تمثل منصة واحدة في كل من Spot والمشتقات، ودفتر الأوامر لقطة قابلة للتغير، ومصدر CFTC أسبوعي وCoin Metrics Community خاضع لشروط الاستخدام غير التجاري. يلزم جمع سجلات Demo فعلية ثم قياس السبريد والانزلاق والعمولات والسحب قبل أي استنتاج عن الأداء.
