# Bitcoin Intelligence Lab — مختبر ذكاء البيتكوين

برنامج مستقل للبحث والتحليل اللحظي للبيتكوين، يجمع بيانات السوق الفوري والمشتقات والسيولة والبلوكشين في محركات منفصلة، ثم يصدر قرارًا مركزيًا قابلًا للتفسير. هذا الفرع مخصص للبرنامج ولا يغيّر الفرع الرئيسي للمستودع.

## المبدأ
- لا مفاتيح AI أو مفاتيح تداول مطلوبة للبيانات العامة.
- لا خلط بين بيانات BTC وبيانات الذهب.
- كل ملاحظة تحمل المصدر والوقت والحالة؛ البيانات القديمة أو الناقصة تمنع القرار بدل ملئها بقيم افتراضية.
- المحركات تحليلية فقط. لا توجد في هذه النسخة واجهة إرسال أوامر إلى منصة تداول.
- لا يُعرض score على أنه احتمال ربح. نجاح الاختبارات لا يثبت ربحية استراتيجية.

## المحركات في الإصدار التأسيسي
1. بيانات Binance Spot: شموع مغلقة، دفتر أوامر، وصفقات مجمعة.
2. بيانات Binance USDⓈ-M Futures: التمويل، الفائدة المفتوحة، ونسبة Taker Buy/Sell.
3. تدفق الأوامر: اختلال العمق، السبريد، وصافي تدفق الصفقات.
4. التحليل الفني: EMA، ATR، RSI، الزخم، وكسر نطاق مؤكد باستخدام الشموع المغلقة.
5. شبكة Bitcoin: الهاش ريت، الرسوم، ازدحام الميمبول.
6. CFTC COT: تمركز عقود Bitcoin وMicro Bitcoin CME بالرمزين 133741 و133742.
7. تقلب الخيارات: مؤشر Deribit DVOL العام.
8. القرار المركزي وجودة البيانات وإدارة المخاطر النظرية.

## التشغيل على Windows
1. ثبّت Python 3.12 أو أحدث.
2. أنشئ بيئة افتراضية: `py -3.12 -m venv .venv`
3. فعّلها ثم نفّذ: `python -m pip install -e ".[ui]"`
4. شغّل: `streamlit run app.py`
5. اختر الرمز والفاصل واضغط تحديث البيانات.

يمكن تشغيل الاختبارات الأساسية دون Streamlit أو اتصال شبكي:
`python -m compileall -q bitcoinlab app.py`
`python -m unittest discover -s tests -v`

## ما لا ندّعيه
لا توجد هنا نتائج ربحية، أو صلاحية لتداول حي، أو سجل أداء حقيقي. يلزم لاحقًا جمع لقطات سوق مؤرخة، تدقيق التزامن وحداثة كل مصدر، مراجعة التنفيذ على حساب تجريبي، ثم تقييم إحصائي خارج العينة. لا تفتح هذه النسخة صفقات تلقائيًا.
