# نموذج تحويل فيديو إلى مواصفات استراتيجية قابلة للاختبار

انسخ هذا النموذج لكل فيديو/قاعدة. لا تملأ الفراغات بالتخمين.

## بيانات المصدر
- معرف الفيديو/الرابط:
- عنوان أو وصف المقطع:
- تاريخ النشر (إن ظهر):
- هل تمت مشاهدة المقطع كاملًا؟ نعم/لا
- نوع الدليل: فيديو / تسجيل شاشة / نص / صوت
- التوقيت داخل المقطع الذي يشرح القاعدة:
- جودة الدليل ومواطن الغموض:

## ما قاله المتحدث حرفيًا
- الفكرة الأساسية:
- شروط الشراء:
- شروط البيع:
- شرط إلغاء الإشارة:
- طريقة وقف الخسارة:
- طريقة جني الربح:
- إدارة الصفقة بعد الدخول:
- الفريمات المستخدمة:
- المؤشرات وإعداداتها كما ظهرت:
- هل توجد استثناءات أو شروط سوقية؟
- هل يشرح قاعدة عامة أم يعرض صفقة واحدة؟

## تحويل الكلام إلى شروط دقيقة
- تعريف الاتجاه:
- تعريف الإشارة:
- هل تعتمد الإشارة على شمعة مغلقة؟:
- لحظة اتخاذ القرار:
- سعر الدخول المفترض:
- شروط عدم التداول:
- الوقف: قاعدة حسابية محددة:
- الهدف: قاعدة حسابية محددة:
- التعامل مع إشارة معاكسة:
- حد السبريد والانزلاق:
- حساب حجم العقد:
- التعامل مع أقل حجم مسموح:
- أقصى عدد مراكز:
- منع تكرار الدخول في الإشارة نفسها:
- السلوك عند فقد البيانات/فشل المؤشر:

أي خانة غير محددة تبقى معلّقة ولا تُحوّل إلى قاعدة صامتة.

## خطة الاختبار
- الرمز الدقيق لدى الوسيط:
- الفريم التنفيذي:
- فريمات التأكيد:
- الفترة التطويرية:
- الفترة المستقلة خارج العينة:
- نوع النمذجة وجودة البيانات:
- العمولة/السبريد/السواب/الانزلاق:
- الإعدادات الثابتة:
- المتغير الوحيد الذي يجري تغييره:
- خط الأساس الذي ستتم المقارنة معه:

## نتائج كل تشغيل
- Commit SHA:
- بصمة المصدر:
- بصمة ملف الإعدادات:
- رابط تشغيل GitHub Actions:
- رابط Artifact:
- أخطاء/تحذيرات الترجمة:
- عدد الصفقات:
- الصفقات الرابحة/الخاسرة:
- صافي الربح بعد التكاليف:
- معامل الربحية PF:
- أقصى تراجع نسبي ومطلق:
- متوسط الربح ومتوسط الخسارة:
- أكبر ربح/خسارة:
- أطول سلسلة خسائر:
- تطابق CSV مع تقرير MT5:
- هل استُخدم أي حقن اصطناعي؟:
- هل هذه نتيجة أداء أم تشخيص فقط؟:
- القرار: قبول مبدئي / رفض / يحتاج دليلًا إضافيًا

## مراجعة ما قبل الدمج
- [ ] يمكن الرجوع إلى دليل المصدر.
- [ ] لا توجد شروط دخول/خروج مخترعة.
- [ ] ترجمة MQL5 موثقة.
- [ ] فحص التنفيذ موثق.
- [ ] تطابق سجل الصفقات وتقرير MT5 موثق.
- [ ] المقارنة تستخدم الفترة والإعدادات نفسيهما.
- [ ] توجد فترة خارج العينة لم تُستخدم لضبط الإعدادات.
- [ ] لم يُعتمد الأداء اعتمادًا على عدد ضئيل من الصفقات الرابحة.
- [ ] لا يوجد تداول حي مفعل.
- [ ] تم حفظ الفشل والأسباب والإعدادات كما تم حفظ النجاح.
