# محرك التحليل الاقتصادي — تقويم BLS للقراءة فقط

يحتوي `economic_calendar.py` على موائم اختياري لملف iCalendar العام الصادر عن مكتب إحصاءات العمل الأمريكي:

- المصدر الوحيد لهذا الموائم: https://www.bls.gov/schedule/news_release/bls.ics
- لا يحتاج مفتاح API أو حسابًا.
- لا يجلب إلا عند استدعاء `fetch_bls_calendar()` يدويًا؛ لا يعمل في الخلفية.
- يقيد الطلب بـHTTPS ونطاق BLS الرسمي ووقت انتظار وحجم استجابة ثابتين، ويحفظ وقت الجلب وبصمة SHA-256.
- يحلل مواعيد الإصدار فقط، بما في ذلك توقيت منطقة America/New_York، ويحوّل الأوقات إلى UTC مع الاحتفاظ بتمييز الأحداث طوال اليوم.
- لا يحتوي الملف على القيمة الفعلية أو توقع المحللين، كما أن تقويم BLS لا يشمل جميع الإصدارات الاقتصادية التي قد تؤثر في الذهب.
- تعطل الإنترنت أو تعذر جلب التقويم لا يمنع استعمال قراءة MT5 ومحرك المؤشرات؛ تُعرض حالة الخطأ فقط.

الاختبارات تستخدم أمثلة iCalendar صغيرة للتحقق من قواعد الصيغة والوقت؛ لا تتضمن أسعار سوق أو محاكاة تداول.

تذكر صفحة BLS الرسمية أن هذا التقويم يحتوي تواريخ نشر معظم الإصدارات المجدولة للمكتب خلال الأشهر القادمة، وأنه قد يتحدث عند الحاجة قبل الموعد بنحو أسبوع أو أكثر:
https://www.bls.gov/schedule/news_release/cpi.htm
