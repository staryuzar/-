# محرك التحليل الفني TV26 وماسح الرسم والاتصال الحي للقراءة فقط

يضم المشروع هذه الوحدات الأولية:
- `technical_rating.py`: حساب 26 تصويتًا فنيًا من OHLCV يمرره المستدعي.
- `pattern_scanner.py`: اتجاه وصفي، ATR، محاور مؤكدة، مناطق دعم/مقاومة تقريبية، اختراقات على إغلاق شمعة مكتملة، ابتلاع سعري، ومرشحات قمتين/قاعين.
- `live_mt5.py`: موائم قراءة فقط يقرأ آخر tick والشموع المكتملة من طرفية MT5 المجهزة مسبقًا ثم يستدعي محرك المؤشرات والماسح.
- `app.py` في جذر المشروع: لوحة عربية تعرض بيانات السعر وحداثتها وحالة المؤشرات ونتائج الماسح.

## تشغيل لوحة Windows

1. افتح MT5 يدويًا وسجّل الدخول داخل الطرفية نفسها؛ البرنامج لا يطلب رقم الحساب أو كلمة المرور.
2. تأكد من ظهور رمز الذهب الصحيح في Market Watch.
3. من مجلد `trading-lab/gold-intelligence-lab` شغّل `START_GOLDLAB_DASHBOARD.bat`.
4. من المتصفح المحلي اضغط «قراءة السوق وتحليل المؤشرات». لا يوجد تحديث تلقائي.
5. إذا كانت لديك أكثر من طرفية MT5، أدخل مسار `terminal64.exe` في اللوحة، أو عرّفه في متغير البيئة `GOLDLAB_MT5_PATH`.

يبدأ موائم MT5 قراءة الشموع من موضع رقم 1، فيستبعد الشمعة المفتوحة. ويعرض وقت السعر والشمعة بوحدة UTC وعمر كل منهما. إذا كان السعر قديمًا أو الشمعة الأخيرة قديمة أو بعض المؤشرات غير جاهزة، يوسم التقرير بأنه غير مؤهل لمراجعة سوق حالية ولا يصنع سعرًا بديلًا.

## ماسح الرسم

الماسح يعمل على الشموع المغلقة التي استلمها من الطرفية. يعتمد القمم/القيعان على شموع يمين ويسار حتى لا يعتبر محورًا غير مكتمل مؤكدًا. مناطق الدعم والمقاومة متوسطات تقريبية لمجموعات من المحاور، وتتغير وفق ATR. ويعرض الاختراقات والابتلاع ومرشحات القمتين/القاعين مع مستوى مرجعي وشرط إبطال وصفي. هذه ليست أوامر دخول أو خروج ولا تضمن احترام السعر للمستويات.

## الحزم

- التحليل والفحوص: `python/requirements-analysis.txt` (NumPy وPandas).
- لوحة Windows وموائم MT5: `python/requirements-ui.txt` (MetaTrader5 وStreamlit بالإضافة إلى حزم التحليل).

كل الولوج للحساب يبقى داخل طرفية MT5. لا توجد حقول لكلمة مرور الحساب أو مفتاح API ولا أي استدعاءات لإرسال أو تعديل أو إغلاق أوامر.

## حدود هذه المرحلة

هذه لوحة أولية تحليلية وليست إصدارًا إنتاجيًا. تطبيق TV26 مستقل ويستخدم ملف ADX معلنًا لأن وصف صفحة المساعدة الحالية يختلف عن لقطة مكتبة TechnicalRating v3 السابقة. لا ندعي تطابقًا رقميًا كاملًا مع TradingView أو ربحية. اختبارات GitHub تفحص عقود الكود وتجميع EA؛ ولم يتم إثبات قراءة حيّة على جهاز المستخدم في هذه المرحلة.
