# محرك التحليل الفني TV26 والاتصال الحي للقراءة فقط

هذا المجلد يضم:
- `technical_rating.py`: حساب 26 تصويتًا فنيًا من OHLCV يمرره المستدعي.
- `live_mt5.py`: موائم قراءة فقط يقرأ آخر quote والشموع المكتملة من طرفية MT5 معدّة مسبقًا ثم يمرر الشموع لمحرك التحليل.
- `app.py` في جذر المشروع: لوحة عربية تعرض السعر والسبريد وحداثة البيانات وتصنيف المؤشرات.

## تشغيل لوحة Windows

1. افتح MT5 يدويًا وسجّل الدخول داخل الطرفية نفسها؛ البرنامج لا يطلب رقم الحساب أو كلمة المرور.
2. تأكد من ظهور رمز الذهب الصحيح في Market Watch.
3. من مجلد `trading-lab/gold-intelligence-lab` شغّل `START_GOLDLAB_DASHBOARD.bat`.
4. من المتصفح المحلي اضغط «قراءة السوق وتحليل المؤشرات». لا يوجد تحديث تلقائي.
5. إذا كانت لديك أكثر من طرفية MT5، أدخل مسار `terminal64.exe` في اللوحة، أو عرّفه في متغير البيئة `GOLDLAB_MT5_PATH`.

يبدأ الموائم قراءة الشموع من موضع MT5 رقم 1، فيستبعد الشمعة المفتوحة. ويعرض وقت السعر والشمعة بوحدة UTC وعمر كل منهما. إذا كان السعر قديمًا أو الشمعة الأخيرة قديمة أو بعض المؤشرات غير جاهزة، يوسم النتيجة بأنها غير مؤهلة لمراجعة سوق حالية ولا يصنع سعرًا بديلًا.

## الحزم

- التحليل والفحوص: `python/requirements-analysis.txt` (NumPy وPandas).
- لوحة Windows وموائم MT5: `python/requirements-ui.txt` (MetaTrader5 وStreamlit بالإضافة إلى حزم التحليل).

الاعتماد الرسمي على `MetaTrader5` يتطلب Windows وطرفية MT5 قابلة للاتصال. كل الولوج للحساب يبقى داخل الطرفية.

## حدود هذه المرحلة

هذه لوحة أولية تحليلية وليست إصدارًا إنتاجيًا. تطبق محرك TV26 قواعد منشورة بصورة مستقلة، مع اختيار ADX موثق لأن وصف صفحة المساعدة الحالية يختلف عن لقطة مكتبة TechnicalRating v3 السابقة. لا ندعي مطابقة رقمية كاملة مع TradingView أو ربحية. لا توجد أي وظيفة لإرسال أو فحص أو تعديل أو إغلاق أوامر التداول.

اختبارات GitHub تفحص عقود الكود وتجميع EA فقط. لم يتم إثبات الاتصال الحي على جهاز المستخدم في هذه المرحلة.
