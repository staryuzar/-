# مصفوفة اكتساب الميزات وخيارات التكامل — Gold Intelligence Lab

هذه المصفوفة تحول بحث المنافسين إلى قرارات هندسية قابلة للتتبع. أسماء البرامج روابط مرجعية للدراسة، وليست تأكيدًا بأن تكاملها متاح لنا أو أن نتائجها دقيقة.

## قاعدة القرار

لكل ميزة نحدد: الوظيفة، أفضل مرجع، وسيلة الوصول الموثقة، مدى الاعتماد على خدمة خارجية، البديل المستقل، ودليل القبول. لا نقبل الاعتماد على API أو حساب مدفوع أو مفتاح غير متاح. ولا نتجاوز تسجيل الدخول أو الترخيص أو ننسخ الشيفرة الداخلية للمنتجات المغلقة.

### تقييم التكامل مقابل البناء

استخدم درجة من 0 إلى 5 لكل معيار، ودوّن أسباب الدرجة:
- ملاءمة الوظائف المطلوبة: 30%.
- إمكانية الوصول والترخيص والتكلفة دون اعتماد على مفتاح غير متاح: 25%.
- جودة البيانات وإمكانية التحقق: 20%.
- الاعتمادية والسرعة: 15%.
- قابلية الصيانة والأمان: 10%.

هذه أوزان قرار أولية لمقارنة الخيارات، وليست قياسًا لربحية التداول. إذا كانت الخدمة لا تسمح قانونيًا بالوصول إلى الوظيفة الأساسية المطلوبة، فذلك قيد مانع ولا تعوضه درجة عالية في بقية المعايير.

## مخطط المعمارية المستهدف

مصادر البيانات ← موائمات مستقلة ← فحص جودة وتوحيد التوقيت ← مخزن موحد ← محركات مستقلة (TV26، الماسح، الأخبار والأساسيات، الاستراتيجيات، المخاطر) ← محرك قرار شفاف ← لوحة المراقبة والسجل. يظل EA مكوّن تنفيذ منفصلًا ولا يتلقى أمرًا للتنفيذ إلا بعد اجتياز بوابة المخاطر والتفويض المحدد.

## قرارات يجب تثبيتها

1. المصدر الحقيقي للسعر هو MT5/الوسيط المتصل؛ لا نستبدله ببيانات مختلقة ولا ندمج أسعار مصادر مختلفة دون توثيق.
2. تنفيذ المؤشرات بصورة مستقلة يعتمد على بيانات MT5/الوسيط. لا تُستخدم بيانات TradingView أو تنبيهاته/Webhooks كمدخل آلي للقرار؛ أي مراجعة لواجهة TradingView تكون بشرية وبصرية فقط، وفق سياسة المنصة.
3. أي خدمة خارجية اختيارية خلف Adapter؛ فشلها لا يجب أن يعطل بيانات السوق الأساسية أو يخفي حالة تعطلها.
4. لا مفتاح API مدفوع مفروض على الخطة. المصدر الذي يتطلب اعتمادًا غير متاح لا يصبح اعتمادًا حرجًا.
5. اختبارات الكود/الترجمة تثبت خصائص برمجية فقط. لا نستخدم Strategy Tester أو أسعارًا اصطناعية لإثبات نجاح السوق أو الربحية.
6. لا تنفيذ حقيقي ولا حتى أمر تجريبي آليًا دون خطة وموافقة منفصلة. الحساب التجريبي يقلل خطر المال الحقيقي لكنه لا يلغي الأثر الفعلي للأوامر التي تُرسل إليه.
7. لا دمج إلى main تلقائيًا؛ كل تغيير يخضع للمراجعة وسجل واضح ونجاح فحوصه الملائمة.
