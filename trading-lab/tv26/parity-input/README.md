# TradingView CSV input — single-file five-timeframe parity

Upload **one** real export generated by `trading-lab/tv26/TradingView_Parity_AllTF_Export.pine`:

- Required filename: `TV26_AllTF.csv`
- Required path: `trading-lab/tv26/parity-input/TV26_AllTF.csv`
- Required branch: `tv26-five-timeframes-arabic-candidate`

## Export steps

1. Open TradingView on the intended gold symbol/provider and set the chart to M1.
2. Add the full Pine script `TradingView_Parity_AllTF_Export.pine` and verify Pine Editor accepts it.
3. Use the chart's **Export chart data** function, with indicator output values included.
4. Save the export as `TV26_AllTF.csv`. Verify it has columns prefixed with `TV26.M1.`, `TV26.M5.`, `TV26.M15.`, `TV26.M30.`, and `TV26.H1.`.
5. Commit the CSV to the required path above. GitHub Actions will start the direct parity workflow automatically.

The workflow downloads the matching MT5 audit CSV from the documented cloud test run; do **not** upload an MT5 audit file manually. The comparator creates one report and one detailed CSV for each timeframe.

## Important

- The Pine exports use confirmed, closed candles; compare the same timestamps and source feed.
- The broker server offset defaults to UTC+3 in the workflow. Verify it before interpreting timestamp mismatches.
- Do not upload broker credentials, MT5 login files, passwords, or tester `.ini` files.
- Until the real TradingView export has been committed and the workflow passes, direct parity remains **PENDING**. Static tests, Pine compilation and internal MT5 formula audit are not substitutes for this comparison.
